# Animated Login & Registration Form 🚀

A modern and responsive **Animated Login & Registration Form** built using HTML, CSS, and JavaScript.
This project features smooth sliding animations, interactive UI elements, and colorful social media icons with hover effects.

## ✨ Features

* Smooth sliding animation between Login and Register forms
* Modern and clean UI design
* Responsive layout for desktop and mobile
* Social media icons with hover effects
* Beginner-friendly and clean code

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Boxicons
* Google Fonts (Poppins)

## 🚀 How to Run

1. Download or clone the repository
2. Open the project folder
3. Run **index.html** in any browser
